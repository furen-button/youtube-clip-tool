# タスク 04: レイアウト統合・既存UIのリファクタリング

## 概要

タスク01〜03で追加したクリップタイムラインUI・クリップパネルを
既存の編集タブレイアウトへ統合し、全体の UX を整える。
冗長になった既存UIを整理・廃止する。

---

## 現状の編集タブ構造

```
edit-left-panel
  └─ videoPlayer
edit-right-panel
  └─ trimming-section
       ├─ 波形 (WaveSurfer)
       ├─ コメント密度オーバーレイ
       ├─ 盛り上がり検出
       ├─ 微調整フレーム設定
       ├─ 微調整ボタン（開始/終了 ×4ずつ）
       ├─ range-slider-container ← タスク01で廃止予定
       └─ trimming-actions（「現在位置を開始に」等）
  └─ メタデータセクション（多数のフィールド）
```

---

## ゴール: 新レイアウト案

clip-timeline-bar（タスク01）と波形・微調整コントロールは同じ時間軸を扱うため、
右パネルの「トリミングセクション」に統合し、一体的に操作できるようにする。

```
┌──────────────────────────────────────────────────────┐
│  edit-left-panel（縦に並ぶ or 左固定）               │
│  ┌────────────────────────────────────────────────┐  │
│  │ videoPlayer                                    │  │
│  └────────────────────────────────────────────────┘  │
│  ┌────────────────────────────────────────────────┐  │
│  │ [clip-panel] ← タスク03                        │  │
│  └────────────────────────────────────────────────┘  │
└──────────────────────────────────────────────────────┘
┌──────────────────────────────────────────────────────┐
│  edit-right-panel（詳細設定 / スクロール可能）        │
│  ┌────────────────────────────────────────────────┐  │
│  │ トリミングセクション（統合）                    │  │
│  │  ├─ ヘッダー（ズーム・正規化・コメント密度）    │  │
│  │  ├─ [clip-timeline-bar] ← タスク01             │  │
│  │  │   └─ ハンドル + 再生ヘッド + 時刻表示       │  │
│  │  ├─ 波形 (WaveSurfer + Regions)                │  │
│  │  ├─ コメント密度オーバーレイ                    │  │
│  │  ├─ 盛り上がり検出                             │  │
│  │  ├─ 微調整フレーム設定 + 微調整ボタン           │  │
│  │  └─ アクションボタン（開始/終了設定・範囲再生） │  │
│  └────────────────────────────────────────────────┘  │
│  ┌────────────────────────────────────────────────┐  │
│  │ メタデータセクション                           │  │
│  └────────────────────────────────────────────────┘  │
└──────────────────────────────────────────────────────┘
```

### 統合のポイント

- **clip-timeline-bar は波形の直上に配置**: ハンドルのドラッグ操作で
  trimState を更新し、直下の WaveSurfer Region と常に同期する
- **同一の時間軸**: clip-timeline-bar・WaveSurfer・コメント密度が
  同じ横幅で並び、時間位置が視覚的に一致する
- **再生ヘッド**: clip-timeline-bar の再生ヘッドと WaveSurfer の
  カーソルが連動して同じ位置を示す
- **range-slider-container を廃止**: clip-timeline-bar が完全に代替する

---

## 廃止・整理する既存UI要素

| 要素 | 対応 |
|---|---|
| `#startSlider` / `#endSlider` (range-slider-container) | タスク01のタイムラインバーに置き換えて削除 |
| `#startTimeDisplay` / `#endTimeDisplay` / `#durationDisplay` (time-display-compact) | クリップパネル（タスク03）とタイムラインハンドルで代替 → 削除またはコンパクト化 |
| `#playTrimmedBtn` 「範囲を再生」 | クリップパネルか波形コントロールへ移動 |
| `#setStartBtn` / `#setEndBtn` | 残す（よく使う操作のため）。微調整ボタン行に統合 |
| `#generateClipUrlBtn` | クリップパネルのURL自動更新で代替 → 削除 |
| `#generateFileNameBtn` | 残す（ファイル名は自動生成のまま） |

---

## レスポンシブ対応

- 画面幅 > 1100px: `edit-left-panel` と `edit-right-panel` を横並び（現状維持）
- 画面幅 ≦ 1100px: 縦並びに変更（ビデオ → クリップパネル → タイムライン統合セクション → メタデータ）

```css
@media (max-width: 1100px) {
  .edit-layout {
    flex-direction: column;
  }
  .edit-left-panel,
  .edit-right-panel {
    width: 100%;
    max-width: none;
  }
}
```

---

## アニメーション

- 動画が新たにロードされたとき、`clip-panel` と統合トリミングセクションをフェードイン表示する
- 動画未選択時は `clip-panel` を `display: none` または `visibility: hidden` + `pointer-events: none`

## 実装ステップ

1. タスク01（タイムラインバー）の実装完了を確認
2. タスク03（クリップパネル）の実装完了を確認
3. `index.html` でレイアウト統合:
   - clip-timeline-bar を `trimming-section` 内の波形の直上に配置
   - clip-panel を `edit-left-panel` の videoPlayer 直下に配置
   - 廃止対象の要素を削除（range-slider-container 等）
4. `renderer.js` から廃止した要素への参照を削除し、対応するイベントリスナーを削除
5. clip-timeline-bar と WaveSurfer の時間軸同期を確認・調整
6. CSS でレイアウト調整・レスポンシブ対応
7. 手動テスト:
   - 動画を選択 → クリップパネル・統合トリミングセクションが表示される
   - clip-timeline-bar のハンドルドラッグ → WaveSurfer Region が連動する
   - 微調整ボタン → clip-timeline-bar のハンドル位置が連動する
   - JSON保存・MP4エクスポートが動く
   - 波形・コメント密度表示が壊れていない

---

## 受け入れ条件

- [ ] clip-timeline-bar が波形の直上に配置され、同一の時間軸で同期している
- [ ] clip-panel が左パネルの videoPlayer 直下に配置されている
- [ ] 廃止した要素が `index.html` / `renderer.js` / `styles.css` から除去されている
- [ ] 廃止後に JavaScript エラーが発生しない
- [ ] clip-timeline-bar のハンドル操作と WaveSurfer Region が双方向に連動する
- [ ] 編集タブ全体が 1100px 以上でも以下でも崩れない
- [ ] 既存機能（WaveSurfer / コメント密度 / メタデータ保存）が引き続き動作する

---

- `index.html` — 廃止要素の削除・レイアウト調整
