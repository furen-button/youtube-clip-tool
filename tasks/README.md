# YouTube クリップGUI 実装ロードマップ

## 概要

YouTubeのクリップ機能に近い体験を提供するGUIを、既存の編集タブへ追加・統合する。

## 構成タスク

| タスク | ファイル | 優先度 | 依存 |
|---|---|---|---|
| 01 タイムラインバーUI | `01-clip-timeline-bar.md` | 🔴 高 | なし |
| 02 サムネイルプレビュー | `02-clip-thumbnail-preview.md` | 🟡 中 | タスク01 |
| 03 クリップパネルUI | `03-clip-panel-ui.md` | 🔴 高 | タスク01 |
| 04 レイアウト統合・リファクタリング | `04-layout-refactor.md` | 🔴 高 | タスク01, 03 |
| 05 renderer.js を単一責任で分割 | `05-renderer-split.md` | 🟡 中 | なし |
| 06 セリフ・ルビ欄への音声認識入力 | `06-serif-stt.md` | 🟢 低 | なし |

## 推奨実装順

```
01 → 03 → 04 → 02
```

1. **タスク01**（タイムラインバー）: UIの土台。他のタスク全ての前提。
2. **タスク03**（クリップパネル）: タイムラインと連動するアクションUI。
3. **タスク04**（レイアウト統合）: 既存UIを整理して全体を繋げる。
4. **タスク02**（サムネイルプレビュー）: エンハンスメント。独立して後回し可。
